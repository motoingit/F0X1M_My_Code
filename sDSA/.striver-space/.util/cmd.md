### DSA — Compile & Run

```bash
g++ main.cpp -o main && ./main.exe
```

### DSA — Input/Output

```cmd
g++ -std=c++20 -O2 -Wall main.cpp -o main && main.exe < .util/input.txt > .util/output.txt
```

### OS — Compile & Run

```bash
gcc os.c -o os && ./os.exe
```

### OS — Compile with Warnings

```bash
gcc -std=c17 -Wall -Wextra -O2 os.c -o os && ./os.exe
```
