## Note

It is not intended to be submitted directly to companies. Or it will typically goes beyond size of A4
Instead, before applying to a company, I will duplicate this master template and create a customized one-page resume by removing or rearranging sections based on the job description.

## Design Requirements

The template should be ATS-friendly.
The design should be minimal, clean, and professional.
Avoid unnecessary graphics or decorations.
Use reusable commands/macros wherever possible.
Organize the code into logical sections (by Comments as for now i dont need section folder as the resume is of one page only but mine was technically one page but very large in length as its master template of my resume ) so it is easy to maintain.
Avoid hardcoded values where possible (margins, spacing, colors, font sizes, etc. should be configurable in another config.tex file that will be imported in main.tex file).

## Important Constraint

Although the master resume will contain much more than one page of content in one each, make the layout, colors, margins , and every spacing in that config file.

Maintain spacing and formatting appropriate for a professional one-page resume.
When I create a company-specific resume, I should be able to remove unnecessary sections and immediately obtain a polished single-page resume without redesigning the layout.

## Goal

The final result should function as a resume database of mine :

One comprehensive master-template.tex.
from where Multiple customized resumes generated from it for different companies by selectively keeping the most relevant content in future.
